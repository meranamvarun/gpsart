# First-release limitations

The 2026-10-11 release decision is **NO-GO**. These limitations must remain next to any later release decision until replaced by traceable evidence.

- Coverage and quality: no 50-case independently reviewed held-out benchmark exists. Recognition rates for shapes and text are unknown.
- Route validity: automated fixtures validate continuity, fixed starts, access policy, distance, version binding, and GPX round trips, but those checks have not been run over the absent held-out set.
- Browsers: no signed manual real-provider journey exists for current Chrome, Firefox, Safari, mobile Chrome, and mobile Safari. Windows-hosted viewport automation is not a substitute for Safari or actual-device evidence.
- Performance: the corrected 20-job run recorded 68.886 seconds p95 end-to-end termination and 75.507 seconds maximum, missing the 30-second p95 target and 60-second cap.
- Provider: the public OpenStreetMap tile service is best effort and has no SLA. A source review, explicit ODbL working classifications, reproducible planning-cost arithmetic, and a protected capture step now exist, but no deployed capture, traffic record, public contact channel, accountable legal/provider decision, vendor quote, or budget approval exists. The provider-obligations gate remains blocked.
- Algorithm and catalogue: only the curated heart and HI templates have calibrated pilot evidence. Feasibility at an arbitrary requested start is not promised.
- Geography: routing evidence is tied to the pinned local data artifact and its recorded coverage; the product must show unknown or unavailable outside that coverage.
